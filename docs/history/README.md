# History (not current guidance)

How the kit got to where it is: the Copilot test transcripts and scorecard from 2026-10, and the source notes the pattern cards were first built from. Nothing here is installed, and parts of it describe rules the kit has since changed (for example page-title and section-header sizes).

The current rules are the files the installer ships: `.github/copilot-instructions.md`, `.github/skills/fluent-ui/` and `.fluent-kit/`. When anything here disagrees with them, they win.

- `SCORECARD.md`, `copilot-prompts.md`: the first Copilot test round, prompt by prompt.
- `research/`: measurements read from Microsoft's Figma files and paraphrased Fluent 2 component guidance.

Current evaluation protocol: `tests/BENCHMARK.md`.
